\doxysubsection{Detailed Description}
Abstract class that represents a flow between two systems. 

The \doxylink{classFlow}{Flow} class defines the basic structure for flows used in the model. Each flow has a source system and a target system, as well as an abstract \doxylink{classFlow_aa1ad5f820c1f10f9e19c555af8bf69f2}{equation()} method that must be implemented by subclasses to calculate the transferred value.
