\doxysubsection{Detailed Description}
Represents a model that contains systems and flows. 

The \doxylink{classModel}{Model} class manages collections of \doxylink{classSystem}{System} and \doxylink{classFlow}{Flow} objects. It is responsible for storing them, updating their states, and executing the simulation logic over a time interval.
